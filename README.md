# Sarahah

•Engineered a secure content-sharing platform, supporting multiple authentication strategies using Passport.js for local accounts and Google/​Facebook OAuth.

•Built a robust media management system by integrating Multer for handling user uploads and Cloudinary for secure cloud storage and delivery of images.

•Developed scalable back-end APIs with Express.js, implemented server-side data validation using Joi, and added unique features like QR code generation for easy content sharing.

Sarahah helps you receive constructive feedback from your friends and coworkers anonymously. Improve yourself by understanding how others perceive you. https://sarahah-beta.vercel.app/
